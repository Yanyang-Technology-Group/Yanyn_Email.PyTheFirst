主要更新内容:
--

双线程处理：
--

使用Python的threading模块创建后台线程处理耗时的网络操作（如获取邮件、发送邮件等）

使用queue.Queue实现线程间通信，主线程定期检查消息队列并更新UI

避免了UI卡顿，提升了用户体验

ㅤ

HTML邮件支持：
--

添加了HTML/纯文本视图切换功能

使用BeautifulSoup解析HTML邮件内容并转换为纯文本显示

发送邮件时支持选择HTML格式，并自动创建纯文本版本作为备选

ㅤ

邮件处理优化：
--

改进了邮件内容解析逻辑，更好地处理多部分邮件

支持显示HTML邮件中的纯文本和HTML内容

添加了HTML到纯文本的转换功能

ㅤ

错误处理和状态反馈：
--

改进了错误处理机制，通过消息队列在主线程显示错误信息

提供了更好的状态反馈
